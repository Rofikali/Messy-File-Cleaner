# LINUX-PATH-EVAL-01 — Linux path resolution reference

Baseline 7d76d2917c8f096182f4b474a6364c076036b476. Existing root_path.h is lexical only and scanner opens a root with O_NOFOLLOW, then uses descriptor-relative single-component traversal and inode/device checks. Root ancestors are not validated by current contract. [Linux openat2 manual](https://man7.org/linux/man-pages/man2/openat2.2.html) and [openat manual](https://man7.org/linux/man-pages/man2/openat.2.html) document that O_NOFOLLOW restricts the final component only, whereas RESOLVE_NO_SYMLINKS rejects symlinks in resolution and RESOLVE_BENEATH confines resolution relative to the directory fd. Reference-only UAPI research, no kernel source copied.

First test-only capability characterization uses installed linux/openat2.h and SYS_openat2, a private mkdtemp fixture with base, real/child, internal alias, sibling outside and relative escape link. Eleven explicit comparisons: three allowed paths with device/inode equality against openat; two baseline openat successes (internal ancestor alias, relative sibling escape); six candidate rejections (internal ancestor alias, final alias, escape link, relative sibling escape, absolute fixture path, missing directory) with ELOOP/EXDEV/ENOENT as appropriate. No reads/writes to user data, no moves; cleanup only known successfully created paths.
