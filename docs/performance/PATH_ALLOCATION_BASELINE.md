# MEMORY-POOL-EVAL-01 — Owned lexical path allocation baseline

Baseline 0bd06059ae41cf4e909d7ab230697e8b63018fdf. Scanner uses fc_copy_root_path/fc_join_path in include/utils/root_path.h, owns directory-frame paths until frame teardown, and frees per-entry paths; frames grow by checked realloc. The shared helper allocates a new buffer via malloc and copies bytes; callers own and free it. Existing scanner resource failure tests remain in force. Ubuntu 24.04 Docker build installs build-essential, CMake and Ninja. GNU libc and alternate allocators are distinct from Linux kernel memory management; reference [GNU C Library](https://www.gnu.org/software/libc/), not a source import or license approval.

First test-only baseline links the unchanged inline fc_join_path helper. Parent lengths 32, 256, 1024 bytes, with/without trailing slash; 64 simultaneously owned outputs, 64 batches per sample, three rounds and alternating length/slash order: 18 samples, 73,728 successful joins/frees on complete execution. Every result checked against independently formatted expectation, one live copy mutated then restored to verify independence of other live copies; reverse frees, cleanup on every failure. Record calls/frees, total requested payload including terminators, peak simultaneous requested bytes and monotonic time including helper, allocation, verification and free. Requested bytes exclude allocator metadata, fragmentation, other arrays and RSS; no direct heap instrumentation or whole-scanner performance claim. No actual paths accessed or files created. Native CTest smoke timeout 15 seconds, no timing threshold. Reproduce Release CMake BUILD_TESTING=ON, build path-allocation-benchmark, ctest -R '^path_allocation_benchmark_smoke$' -V. Local tests NOT RUN at creation; exact-head CI required.

Do not replace ownership with borrowed arena/scratch memory without proving lifetime, cancellation, allocation-failure and concurrency contracts; this benchmark does not model directory-depth retention or scanner I/O. Later candidate comparison must preserve semantics and measure memory cost. No external imports/dependencies, production allocator or API/ABI changes, new workflow dispatch, release or spending. FS-01B/REL-01 and license lock unchanged. L1–L7/security/Linux/SRE: bounded independent baseline and cleanup; network N/A; CA/MBA/management: avoid unproven integration/maintenance cost.
